# 基于 STM32H7 的嵌入式机器视觉 PCB 缺陷检测系统

针对 PCB 生产行业人工目视检测效率低、漏检率高、传统 PC 机器视觉设备成本高昂的痛点，设计一套基于 STM32H7 的嵌入式机器视觉 PCB 缺陷检测系统。采用上下位机协同架构完成工业 PCB 自动化质检，将图像预处理、深度学习推理、人机交互全部部署于嵌入式单片机本地运行，无需工控机持续运行，兼顾低成本与实时性。

## ✨ 功能特性

- 📷 **工业相机采集**：奥普特 GigE 工业相机高清 PCB 图像采集，Lanczos 缩放预处理
- 📡 **WiFi-TCP 通信**：自定义 TCP 协议帧传输 RGB 图像，24h 连续运行零断连
- 🧠 **端侧 AI 推理**：TensorFlow Lite Micro 部署 FOMO 轻量化目标检测模型，INT8 量化
- 🔍 **三类缺陷检测**：精准识别 PCB 开路、短路、漏孔三类典型缺陷
- 📊 **坐标映射定位**：缺陷检测结果坐标映射，支持图像标注框绘制
- 🖥️ **TouchGFX 交互**：4.3 寸 RGB 触摸屏，实时显示原图、缺陷标注、置信度、统计信息
- 🌐 **Web 仪表盘**：Flask Web 服务，管理员登录、实时缺陷查看、数据导出
- ⚙️ **硬件联动**：GPIO 中断触发检测、蜂鸣器报警、SG90 舵机分拣、传送带控制
- 🚀 **高速响应**：单张 PCB 图像检测耗时低于 300ms
- 🎯 **高精度**：缺陷识别准确率 96%+，F1 评分 0.90

### 软件分层 (RT-Thread 多任务)

| 层级 | 模块 | 功能 |
|------|------|------|
| 应用层 | display | TouchGFX 界面渲染、缺陷标注、统计显示 |
| 应用层 | ai | TFLite Micro 推理、缺陷解析、坐标映射 |
| 通信层 | wifi_tcp | WiFi 连接管理、TCP 图像接收、环形缓存 |
| 驱动层 | LCD/LTDC 驱动 | 4.3 寸屏显示驱动 |
| 驱动层 | SDIO/WLAN 驱动 | AP6212 WiFi 模块驱动 |
| 驱动层 | GPIO/PWM 驱动 | 中断触发、舵机控制、蜂鸣器 |

### 检测流程
GPIO 中断触发 → WiFi 发送拍照指令 → 上位机采集图像 → TCP 传输 RGB 数据

↓

结果输出 ← 缺陷坐标映射 ← TFLite 推理 ← 像素格式转换 ← 图像缩放填充

↓

TouchGFX 显示 + Web 上传 + 蜂鸣器报警 + 舵机分拣 + 传送带联动


### 核心算法

| 算法 / 模型 | 说明 |
|-------------|------|
| FOMO-MobileNetV2 | 轻量化目标检测骨干网络 |
| INT8 量化 | Edge Impulse 训练导出，模型体积仅 54.6KB |
| TensorFlow Lite Micro | 端侧推理引擎，STM32H7 本地运行 |
| 查表法像素转换 | 规避浮点运算，降低单片机算力消耗 |
| Lanczos 缩放 | 上位机图像预处理，等比例缩放适配模型输入 |

## 🚀 使用说明

### 1. 开发环境

- **下位机 (STM32H7)**：RT-Thread Studio
- **上位机 (PC)**：Python 3.x + OpenCV + Flask
- **模型训练**：Edge Impulse
- **界面开发**：TouchGFX Designer
- **下载调试**：ST-Link V2

### 2. 关键参数

```c
// 模型输入尺寸
#define FOMO_INPUT_WIDTH     96
#define FOMO_INPUT_HEIGHT    96
#define FOMO_INPUT_CHANNELS  3

// 缺陷类别
#define DEFECT_OPEN_CIRCUIT  0   // 开路
#define DEFECT_SHORT_CIRCUIT 1   // 短路
#define DEFECT_MISSING_HOLE  2   // 漏孔

// 置信度阈值 (可通过 TouchGFX 界面调整)
#define CONFIDENCE_THRESHOLD 0.6f

// TCP 通信
#define TCP_SERVER_PORT      8888
```

### 3. 快速上手

- **上位机运行 pc_server.py，连接工业相机，启动 TCP 服务与 Flask Web**
- **下位机烧录 RT-Thread 固件，配置 WiFi SSID / 密码**
- **系统上电自动连接 WiFi（上下位机需连同一网络），建立 TCP 连接**
- **光电传感器触发 → 自动拍照检测 → 屏幕显示结果 → 舵机分拣**
- **Web 端访问 http://<PC_IP>:5000 查看检测仪表盘**

### 4. 模型替换
将训练好的 .tflite 模型文件放入 tflite_model/ 目录，替换 model_data.cc 中的模型数组：
```c
// 量化模型数组
const unsigned char g_model_data[] = {
    0x1c, 0x00, 0x00, 0x00, 0x54, 0x46, 0x4c, 0x33, ...
};
const int g_model_data_len = 54600;  // 54.6KB
```
